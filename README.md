# PROG6112 Road Accident Test – Corrections

This repository contains the correction code for the PROG6112 Road Accident Mock Test.

The solutions cover:

- **Question 1:** 1D and 2D arrays, loops, calculations and determining the city with the highest number of accidents.
- **Question 2:** Interfaces, abstract classes, inheritance, constructors, getters, `@Override` and `super()`.

## Important

Please do not only copy the code. Make sure you understand:

- How the 1D and 2D arrays work.
- How `x` is used to move through the cities.
- How `accidents[x][0]` and `accidents[x][1]` access the car and motorbike accident values.
- How the total for each city is calculated.
- How the city with the highest number of accidents is determined.
- How the interface, abstract class and subclass work together.
- Why `implements`, `extends`, `@Override` and `super()` are used.

Use this repository together with the corrections covered during the booster session when preparing for the PROG6112 test.
